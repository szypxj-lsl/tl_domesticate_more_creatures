# TL Domesticate More Creatures 设计规格

## 目标

将 `tl_biological_attribute_panel` 全面迁移为 `tl_domesticate_more_creatures`，保留旧版自身数据兼容迁移，移除 FindMe Salvation 兼容；在现有等级、属性、天赋、繁殖和面板基础上新增独立驯服、眩晕、麻醉箭、宠物 AI、防友伤，以及可选 `tl_marking` 指令联动。

## 身份迁移

- 新 Mod ID：`tl_domesticate_more_creatures`
- Java 根包：`com.szypxj.tldomesticatemorecreatures`
- 主类：`TlDomesticateMoreCreatures`
- 命令根：`/tdmc`
- 配置、资源、数据包、语言键、网络频道、创造页签、物品 ID 全部改用新命名空间。
- 旧 `tl_biological_attribute_panel` 仅作为兼容读取来源：旧 Progress NBT 自动迁移，新数据只写新键；旧物品 Missing Mapping 重定向；旧 entity_rules namespace 可兼容读取。
- FindMe Salvation 兼容代码全部删除，不迁移其驯服数据。

## 眩晕属性

- 正式新增属性定义 `torpor`，参与初始点、升级点、天赋点、遗传和驯养随机点。
- 玩家基础最大眩晕值 1000；其他生物基础最大眩晕值 500。
- 最大眩晕值公式：`base * (1 + (torporTotalPoints + initialLevel) * 0.05)`；0.05 可配置。
- 玩家始终拥有眩晕；非玩家由独立 BLACKLIST/WHITELIST 控制。
- 当前眩晕未达到最大值时完全正常行动。
- 当前眩晕第一次达到最大值时进入昏迷锁定；必须自然恢复到 0 才苏醒，即使中途已经低于最大值也仍保持昏迷。
- 无麻醉效果时每秒降低最大眩晕值的 1%，比例可配置；普通实体采用时间戳懒计算，昏迷实体允许轻量定期检查。

## 麻醉效果与麻醉箭

- 新效果 `narcotic`。
- 每级每秒增加 25 点眩晕（I=25/s、II=50/s、III=75/s），基础值可配置。
- 麻醉效果存在时暂停自然恢复；达到最大值封顶。
- 新物品 `narcotic_arrow`，支持弓和弩，默认施加麻醉 I 10 秒，持续时间和等级可配置。
- 默认配方：箭 + 蜘蛛眼 -> 1 麻醉箭。

## 驯服系统

- 自定义驯服数据保存 owner UUID、tamed、taming player、progress、昏迷期间累计伤害等。
- 原生 `TamableAnimal` 仍兼容；自定义规则可覆盖原生驯服方式。
- 规则文件：`config/tl_domesticate_more_creatures/taming_rules.toml`，带中文注释。
- 两组规则：`[[knockout]]` 和 `[[feeding]]`；同一实体不能同时属于两组，冲突则整条规则失效并记录错误。
- 每种食物可配置 amount，多种食物按百分比统一累计驯服进度。
- 第一次有效喂食锁定驯养玩家。
- FEED：可直接喂食，进度持久保存直至成功。
- KNOCKOUT：仅昏迷时可喂食；生物苏醒时进度、玩家锁定、伤害记录全部清零。
- 成功驯服后获得驯养加成。FEED 和原生驯服获得完整默认加成；KNOCKOUT 受昏迷后受伤影响。
- 驯养效率：`max(0, 1 - damageDuringKnockout / maxHealthAtKnockout)`；实际驯养加成 = 默认驯养加成 * 驯养效率；治疗不恢复效率。
- 驯养加成等级产生的属性点全部随机加入初始点，不可重置、不可手动分配。

## 昏迷行为

- 非玩家：停止 AI、导航、攻击、跳跃、主动移动/转向；保留重力、碰撞和受伤。
- 玩家：禁止移动、跳跃、攻击、挖掘、使用/放置物品和实体/方块交互；允许转视角、聊天、背包和菜单。
- 昏迷后受到任何伤害都会计入 KNOCKOUT 驯养效率损失。

## 宠物 AI 与防友伤

- 自定义宠物拥有统一主人关系；默认跟随主人、协助主人攻击、主人受击时反击。
- 不攻击主人、同主宠物、同队/友军。
- 防友伤默认开启，覆盖普通攻击、投射物、可追溯来源的爆炸和范围伤害；匿名 DamageSource 无法可靠归因时不强行猜测。
- 同主双亲繁殖的后代自动归同一主人，不触发额外驯养加成；主人不同或仅一方有主人时不自动归属。

## 望远镜与属性面板

- 玩家和受眩晕系统影响的实体均显示眩晕当前/最大条。
- 宠物 F 面板只显示眩晕属性，不显示驯服方式/食物/进度。
- 未驯服且存在自定义规则的生物，望远镜显示驯服方式、食物和条状驯服进度。
- 望远镜整体改窄、纵向加长，减少横向遮挡。

## tl_marking 指令联动

- `tl_marking` 为可选依赖；未加载时指令系统完全不启用。
- 长按中键继续复用 tl_marking 六格轮盘：注意、集合、防守、危险、攻击、撤退。
- 普通中键智能命令：对准方块/地面=前往；对准可攻击实体=攻击；友方实体不生成攻击命令。
- Shift+中键对准自己的宠物切换多选；有选择集合时命令只发给选中宠物，否则发给同维度已加载且 64 格内的全部自己的宠物。
- 攻击在目标消失/死亡/新命令时结束；集合/前往到达后结束；撤退回主人后结束；注意默认 10 秒；防守/危险持续到新命令。
- 指令范围默认 64 格，可配置。

## 性能约束

- 禁止全世界每 Tick 扫描实体。
- 眩晕普通恢复使用时间戳懒计算。
- 指令只在发出时查询限定 AABB 或选择集合。
- 防守目标搜索有冷却。
- 不重新引入强制所有生物名称牌渲染。
