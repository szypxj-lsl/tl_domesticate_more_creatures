TL Domesticate More Creatures
Minecraft 1.20.1 / Forge 47.4.10 / Java 17
Mod ID: tl_domesticate_more_creatures

本工程由原 TL Biological Attribute Panel 迁移并扩展为完整的生物驯养、等级、属性与宠物指令模组。

主要内容：
- 野生生物随机等级、初始属性点、天赋与遗传
- 玩家/宠物虚拟经验、升级和属性分配
- 驯养加成与昏迷受伤导致的驯养效率损失
- 眩晕属性、麻醉效果与麻醉箭
- 眩晕驯服与直接喂食驯服，可按实体 ID 配置
- 自定义宠物主人关系、跟随/协战/防守与防友伤
- F 键属性面板与原版望远镜生物信息面板
- 可选 tl_marking 联动：中键智能指令、长按轮盘指令、Shift+中键多选宠物
- 动态属性、天赋与实体数据包规则
- 属性重置水晶、宠物经验药水和独立创造页签
- /tdmc 管理命令
- 旧 tl_biological_attribute_panel Progress/配置/物品 ID 兼容迁移
- 中英文 I18N
